## 🚀 How to Install

### For End-Users (APK):
1. Click the **[APK Download Link](https://github.com/Oviya-Babu/tic-tac-toe-android/releases/latest)** in the [Releases](https://github.com/Oviya-Babu/tic-tac-toe-android/releases) section.
2. Transfer the downloaded `.apk` file to your Android device (if downloaded on your PC).
3. Enable **"Install from Unknown Sources"** in your device’s settings:
   - Go to **Settings** → **Security** → Enable **Unknown Sources**.
4. Tap on the `.apk` file to install the app.
5. Open the app and enjoy playing Tic-Tac-Toe!

---

### For Developers (AAB):
1. Download the **[AAB file](https://github.com/Oviya-Babu/tic-tac-toe-android/releases/latest)** from the [Releases](https://github.com/Oviya-Babu/tic-tac-toe-android/releases) section.
2. Use the AAB with:
   - **Android Studio**: Import the `.aab` file into your project for testing or debugging.
   - **Bundletool**: Generate APKs for installation or distribution using the following command:
     ```bash
     bundletool build-apks --bundle=app-release.aab --output=output.apks
     ```
3. Install the generated APKs on your Android device.
