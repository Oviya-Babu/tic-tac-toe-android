# 🎮 Tic-Tac-Toe Android App

A simple yet fun **Tic-Tac-Toe Android game** built as a learning project to explore Android development and app publishing, with guidance from OpenAI GPT.

---

## ✨ Features

- Classic two-player and play vs Computer Tic-Tac-Toe gameplay
- Clean and minimalistic user interface
- Lightweight and easy to use
- Built with Android Studio
- Includes signed APK and AAB ready for distribution
- Try to win hard level with Computer
